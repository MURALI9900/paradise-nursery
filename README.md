# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shopping application that allows users to browse houseplants, add plants to a shopping cart, update quantities, remove items, and view the total cart cost.

## Project Features

- Landing page with Paradise Nursery branding and a Get Started button
- Houseplants organized into multiple categories
- Plant cards with thumbnails, names, prices, and Add to Cart buttons
- Redux Toolkit for cart state management
- Dynamic cart item count
- Increase and decrease item quantities
- Remove plants from the cart
- Dynamic total item count and total cost
- Continue Shopping navigation
- Checkout placeholder message

## Technologies

- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- JavaScript
- CSS

## Project Structure

- `src/App.jsx` - Application routes and landing page
- `src/App.css` - Application and landing-page styling
- `src/components/AboutUs.jsx` - Company information
- `src/components/ProductList.jsx` - Plant catalog
- `src/components/CartItem.jsx` - Shopping cart
- `src/components/Navbar.jsx` - Navigation and cart count
- `src/redux/CartSlice.jsx` - Redux cart state and reducers
- `src/redux/store.js` - Redux store configuration

## Purpose

This project demonstrates a complete plant shopping workflow using React and Redux, including reusable components, routing, state management, and dynamic cart calculations.
